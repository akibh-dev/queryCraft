# Cost model `mvp-1`

The campaign uses deterministic teaching estimates. Each puzzle describes a virtual table and a fixed projection with equality and half-open numeric range predicates joined by AND. The row fixture independently verifies the query’s result multiset, including duplicate rows.

| Quantity                    | Rule                                                                                                                                                                                                                                                                                                                                                     |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Rows examined               | A scan examines all virtual rows. An index lookup examines the estimated rows for its index predicate. Multiply independent filter fractions to estimate the final number of matches. Equality on a non-null key uses one divided by distinct count. A range uses its share of the modeled numeric interval. Round row estimates to the nearest integer. |
| Sequential and random pages | Assume a cold cache and 8,192-byte pages. A scan reads rounded-up data pages. An index lookup adds tree traversal and estimated random data pages.                                                                                                                                                                                                       |
| Cost and latency            | Sequential pages cost one unit and random pages cost four. Each examined row adds 0.001 units per predicate with a minimum charge of one predicate. Latency is 0.1 ms plus 0.02 ms per cost unit.                                                                                                                                                        |
| Optional index storage      | Average key width plus eight bytes per indexed row, rounded up to whole pages.                                                                                                                                                                                                                                                                           |
| Optional write overhead     | 15 times the combined optional tree heights times the ratio of writes to operations, expressed as a percentage. Fixed indexes are included in the baseline.                                                                                                                                                                                              |

The cheapest unrounded cost wins, with ties favoring the scan then index ID order. Objective checks use unrounded metrics. Correctness and all mandatory objectives earn one star. All silver objectives add a second star. All gold objectives add a third after silver passes. The tutorial’s indexed lookup illustrates how latency falls while storage and write costs rise.
