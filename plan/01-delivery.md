## Standard local checks

A0 supplies package scripts for `pnpm dev`, `pnpm lint`, `pnpm typecheck`, `pnpm test` (single run), `pnpm validate:levels`, `pnpm build`, `pnpm preview`, and `pnpm test:e2e`. The content validation script can be registered when B2 lands. CI uses the committed lockfile and installs the Playwright browsers it runs. Browser tests start their own production preview. Each feature owner runs relevant checks; the coordinator runs the full set at integration gates.

## Copyable assignment

“You own [ID] from plan/01-delivery.md. Read its prerequisite outputs and the relevant numbered guide. Edit only its listed paths. Implement the smallest complete behavior described in the row, including its failure states. Run its acceptance check. Report changed paths, exported interfaces, commands and results, and the exact steps the coordinator should use to verify the handoff.”

A ticket is blocked if a required input or exported contract is missing. Name the missing field or module and its owner. Continue independent work with an explicitly labeled test fixture where feasible. Only the coordinator changes scope or dependency order.
